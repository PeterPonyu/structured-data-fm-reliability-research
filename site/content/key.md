# Key included vs key excluded

This path does not host figures or result numbers.

The scripts can run two feature conditions:

- **Key included** — the leave-group-out / rolling-origin key stays in the
  feature matrix.
- **Key excluded** — the split key is dropped. Leave-group-out test keys are
  unseen categories, so this is the conservative bound.

Counts and coverage tables are not published on this leaf.
